# University DB App

Spring Boot 4 application for the university database lab. The project uses a schema-first MySQL database, JPA entities, Spring Data repositories, and read-only REST endpoints.

See [SUBMISSION_CHECKLIST.md](SUBMISSION_CHECKLIST.md) for the PDF contents and screenshots to capture.

## One-time setup

### 1. Install prerequisites

- JDK 17 or newer. JDK 18 is also supported.
- MySQL 8 or XAMPP/MariaDB with MySQL running on port `3306`.
- Git, if you need to push changes.

Check Java with:

```powershell
java -version
```

### 2. Create the database

Open MySQL Workbench, phpMyAdmin, or the MySQL client and run these scripts in order:

```text
sql/schema.sql
sql/data.sql
```

The schema script creates the `university_db` database and its tables. The data script inserts the sample departments, lecturers, courses, students, and enrollments.

The other files in `sql/` are exercises and checks for anomalies, constraints, and joins. Do not run `schema-violations.sql` inserts unless you are intentionally testing a failure.

### 3. Configure the connection once

The default configuration in `src/main/resources/application.properties` is for XAMPP:

```properties
spring.datasource.url=jdbc:mysql://localhost:3306/university_db?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=UTC
spring.datasource.username=root
spring.datasource.password=
```

If your MySQL user has a password, create `src/main/resources/secrets.properties` and keep it out of Git:

```properties
spring.datasource.password=your-password
```

Then import it from `application.properties`, for example:

```properties
spring.config.import=optional:classpath:secrets.properties
```

Keep `spring.jpa.hibernate.ddl-auto=validate`. Hibernate checks the existing schema but does not create or alter tables.

### 4. Start the application

From the project root, use the Maven wrapper:

```powershell
$env:JAVA_HOME='C:\Program Files\Java\jdk-17'
$env:Path="$env:JAVA_HOME\bin;$env:Path"
.\mvnw.cmd spring-boot:run
```

On macOS/Linux, use:

```bash
export JAVA_HOME=/path/to/jdk-17
./mvnw spring-boot:run
```

The application starts at `http://localhost:8080`.

## REST endpoints

- `GET /api/students`
- `GET /api/students?name=sil`
- `GET /api/students/S001`
- `GET /api/students/S001/enrollments`
- `GET /api/courses`
- `GET /api/courses?minCredits=4`
- `GET /api/courses?department=Computer%20Science`
- `GET /api/courses/CS101/students`
- `GET /api/departments/D01/lecturers`
- `GET /api/enrollments?grade=A`
- `GET /api/reports/course-counts`

SQL generated by Hibernate is printed because `spring.jpa.show-sql=true`.

## Build and test

Use JDK 17 or newer:

```powershell
.\mvnw.cmd clean compile
.\mvnw.cmd test
```

The integration context test requires MySQL and the `university_db` schema to be available.
